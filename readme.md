# VisionDoc-RAG

A multimodal RAG system for technical document understanding.

## Project Goal

VisionDoc-RAG aims to build a multimodal document understanding
and retrieval system capable of processing:

- Text
- Tables
- Images
- Figures

and answering user questions with corresponding evidence.
